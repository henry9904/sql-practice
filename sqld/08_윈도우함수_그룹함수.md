## ★ 윈도우 함수 (Window Function)

- 분석 함수 / 순위 함수라고도 함
- **OVER 키워드 필수**

```sql
SELECT WINDOW_FUNCTION(인수)
  OVER (
    [PARTITION BY 칼럼]   -- 그룹 기준
    [ORDER BY 칼럼]        -- 정렬 기준
    [WINDOWING 절]         -- 범위 지정
  )
FROM 테이블;
```

## 순위 함수

| 함수 | 동일값 처리 | 예시 (1,1,1,?) |
|---|---|---|
| `RANK()` | 같은 순위 부여, 다음 순위 건너뜀 | 1,1,1,4 |
| `DENSE_RANK()` | 같은 순위 부여, 다음 순위 안 건너뜀 | 1,1,1,2 |
| `ROW_NUMBER()` | 동일값도 고유 순위 부여 | 1,2,3,4 |

```sql
SELECT JOB, ENAME, SAL,
  RANK() OVER (ORDER BY SAL DESC) ALL_RANK,
  RANK() OVER (PARTITION BY JOB ORDER BY SAL DESC) JOB_RANK
FROM EMP;
```

## 그룹 함수

### ★ ROLLUP
- N개 칼럼 → N+1 레벨 소계 생성
- **계층 구조** → 인수 순서 바뀌면 결과 바뀜

```sql
SELECT DNAME, JOB, COUNT(*), SUM(SAL)
FROM EMP, DEPT
WHERE DEPT.DEPTNO = EMP.DEPTNO
GROUP BY ROLLUP(DNAME, JOB);
-- DNAME별+JOB별 소계, DNAME별 소계, 전체 합계
```

### ★ CUBE
- 결합 가능한 **모든 값에 대해 다차원 집계** 생성
- 인수 순서 달라도 결과 동일

```sql
GROUP BY CUBE(DNAME, JOB);
-- DNAME+JOB, DNAME만, JOB만, 전체 합계
```

### ★ GROUPING SETS
- 원하는 부분의 소계만 선택적으로 추출
- 인수는 평등한 관계 → 순서 바뀌어도 결과 동일

```sql
GROUP BY GROUPING SETS(DNAME, JOB);
-- DNAME별 소계 + JOB별 소계만 (전체 합계 없음)
```

- `GROUPING(칼럼)` = 1: 소계로 계산된 행 / = 0: 일반 집계 행

## DCL (Data Control Language)

- `GRANT`: 권한 부여
- `REVOKE`: 권한 취소

### ★ ROLE
- 유저와 권한 사이의 중개자
- 관리자가 ROLE 생성 → 권한 묶음을 ROLE에 부여 → ROLE을 유저에게 부여

```sql
GRANT DBA TO 유저명;
REVOKE DBA FROM 유저명;
```
