# 01. 데이터 모델링의 이해 (1과목)

> 출제: 10/50문항 | ★ = 시험 빈출

---

## 1. 모델링

- 정의: "다양한 현상을 표기법에 의해 표기하는 것"
- ★ 특징 3가지: **추상화, 단순화, 명확화**
- 3가지 관점: 데이터 관점, 프로세스 관점, 상관 관점
- 3단계 진행:
  - **개념적** — 추상화 수준 높음, 업무 중심, 포괄적
  - **논리적** — Key/속성/관계 정확하게 표현, 높은 재사용
  - **물리적** — 성능/저장 등 물리 성격 고려 설계

> 계획→개념적 / 분석→논리적 / 설계→물리적  
> (실제: 분석→개념+논리 / 설계→물리)

---

## 2. 데이터 독립성

- DB 3단계 구조: **외부단계 / 개념적단계 / 내부적단계**
- 독립성 요소: 외부스키마 / 개념스키마 / 내부스키마
- ★ 사상(Mapping): "상호 독립적인 개념을 연결시켜주는 다리"
  - 외부적/개념적 사상 + 개념적/물리적 사상

---

## 3. 데이터 모델링 3요소

| 개념 | 집합/복수 | 개별/단수 |
|---|---|---|
| 어떤 것 | 엔터티타입(Entity Type) | 엔터티(Entity) |
| 어떤 것 간의 연관 | 관계(Relationship) | 패어링(Pairing) |
| 어떤 것의 성격 | 속성(Attribute) | 속성값(Attribute Value) |

- ★ 좋은 데이터모델 요소: **완전성 / 중복배제 / 업무규칙 / 데이터재사용 / 의사소통 / 통합성**

---

## 4. 엔터티 (Entity)

- 개념: "실체, 객체"
- 특징: 업무필요정보 / 식별자로 식별가능 / 인스턴스집합 / 속성포함 / 관계존재

- ★ 분류 (유무형): **유형, 개념, 사건** 엔터티
- ★ 분류 (발생시점): **기본, 중심, 행위** 엔터티

---

## 5. 속성 (Attribute)

- 정의: "업무에서 필요로 하는 인스턴스로 관리하고자 하는 의미상 더 이상 분리되지 않는 최소의 데이터 단위"
- ★ 특성에 따른 분류: **기본속성, 설계속성, 파생속성**
- ★ 도메인: "각 속성이 가질 수 있는 값의 범위"
- 한 개의 속성 → 한 개의 속성값 (다중값이면 별도 엔터티로 분리)

---

## 6. 관계 (Relationship)

- 정의: "엔터티의 인스턴스 사이의 논리적인 연관성"
- 표기법 3요소: **관계명, 관계차수(1:1/1:M/M:N), 관계선택사양(필수/선택)**
- ERD: 존재에 의한 관계 / 행위에 의한 관계

---

## 7. 식별자 (Identifier)

- ★ 특징: **유일성, 최소성, 불변성, 존재성**
- ★ 분류:
  - 주식별자 / 보조식별자
  - 내부식별자 / 외부식별자(FK)
  - 단일식별자 / 복합식별자
  - 본질식별자 / 인조식별자

- **식별자 관계**: 부모 PK가 자식 PK에 포함 → NULL 불가, 부모 먼저 생성
- **비식별자 관계**: 부모 PK가 자식 FK지만 PK는 아님 → 일반 속성으로 사용
