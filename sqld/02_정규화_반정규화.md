# 02. 정규화 & 반정규화 (1과목)

> ★ = 시험 빈출

---

## 정규화 (Normalization)

- ★ 정의: "데이터에 대한 중복성을 제거하여 준다"
- 정규화 잘 되어 있으면 → **입력/수정/삭제 성능 향상**
- 반정규화 많이 하면 → **조회 성능 향상**
- ★ 함수적 종속성(Functional Dependency): 데이터들이 어떤 기준값에 의해 종속되는 현상
  - 결정자 예) 주민등록번호 → 종속자 예) 이름, 출생지, 주소

| 정규형 | 조건 |
|---|---|
| 1NF | 속성값이 원자값 (반복 칼럼 제거) |
| 2NF | 부분 함수 종속 제거 (복합PK에서 일부에만 종속 제거) |
| 3NF | 이행 함수 종속 제거 (A→B→C 관계 분리) |

---

## 반정규화 (De-normalization)

- 정의: "정규화된 엔터티/속성/관계에 대해 성능향상과 개발·운영의 단순화를 위해 중복, 통합, 분리 등을 수행하는 데이터 모델링 기법"
- 적용 시점: 조인으로 인한 성능 저하가 예상될 때

### 반정규화 기법

| 종류 | 방법 |
|---|---|
| 테이블 반정규화 | 테이블 병합 / 테이블 분할 / 테이블 추가 |
| 칼럼 반정규화 | 중복칼럼 추가 / 파생칼럼 추가 / 이력테이블칼럼 추가 |
| 관계 반정규화 | 중복관계 추가 |

---

## 대량데이터 성능

- **로우 체이닝(Row Chaining)**: 로우 길이가 너무 길어 두 개 이상 블록에 저장
- **로우 마이그레이션(Row Migration)**: 수정된 데이터가 다른 블록으로 이동

### 파티션 종류
- **RANGE PARTITION**: 범위 기준 분할
- **LIST PARTITION**: 목록 기준 분할
- **HASH PARTITION**: 해시 기준 분할

---

## 인덱스 & PK/FK 성능

- ★ PK 칼럼 순서가 인덱스 효율에 직결
- 앞쪽 속성값이 `=` 또는 `BETWEEN`이어야 인덱스 효율 좋음
- FK 제약 걸렸을 때 → **반드시 FK 인덱스 생성**

---

## 분산 데이터베이스

- 정의: "빠른 네트워크로 DB를 여러 지역/노드에 위치시켜 성능 극대화"
- 투명성: 분할 / 위치 / 지역 사상 / 중복 / 장애 / 병행

### 분산 기법

| 기법 | 설명 |
|---|---|
| 테이블위치분산 | 테이블을 다른 서버에 위치 |
| 테이블분할분산 | 수평분할 / 수직분할 |
| 테이블복제분산 | 부분복제 / 광역복제 |
| 테이블요약분산 | 분석요약 / 통합요약 |
