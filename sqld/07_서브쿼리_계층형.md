# 07. 서브쿼리 & 계층형 질의 (2과목)

> ★ = 시험 빈출

---

## 서브쿼리

"하나의 SQL문 안에 포함되어 있는 또 다른 SQL문"

- 서브쿼리는 메인쿼리의 칼럼을 모두 사용 가능
- 메인쿼리는 서브쿼리의 칼럼 사용 불가
- 괄호로 감싸서 사용
- **ORDER BY 사용 불가** (인라인뷰 제외)

---

## 서브쿼리 종류 (위치별)

### ★ 스칼라 서브쿼리 (SELECT 절)
- 한 행, 한 칼럼만 반환

```sql
SELECT ENAME, (SELECT DNAME FROM DEPT WHERE DEPT.DEPTNO = EMP.DEPTNO) AS DNAME
FROM EMP;
```

### ★ 인라인뷰 (FROM 절) = 동적뷰
- FROM 절에서 사용, ORDER BY 사용 가능
- ★ Oracle에서 ROWNUM으로 결과 일부 추출 가능 (TOP-N 쿼리)

```sql
SELECT *
FROM (SELECT ENAME, SAL FROM EMP ORDER BY SAL DESC)
WHERE ROWNUM <= 5;
```

### 중첩 서브쿼리 (WHERE 절)

```sql
-- 단일행 서브쿼리: 결과가 반드시 1건 이하
SELECT * FROM PLAYER
WHERE TEAM_ID = (SELECT TEAM_ID FROM PLAYER WHERE PLAYER_NAME = '손흥민');

-- ★ 다중행 서브쿼리: IN, ALL, ANY, SOME, EXISTS
SELECT REGION_NAME, TEAM_NAME FROM TEAM
WHERE TEAM_ID IN (
  SELECT TEAM_ID FROM PLAYER WHERE PLAYER_NAME = '정현수'
);
```

### HAVING / UPDATE / INSERT에서도 사용 가능

## ★ 뷰 (VIEW)

- 테이블은 실제 데이터를 가짐
- **뷰는 실제 데이터를 가지지 않음** — 실행 시 쿼리를 실행한 결과

---

## 계층형 질의

"테이블에 계층형 데이터(상하관계)가 있을 때 사용"  
예: 조직도, 메뉴, 사원-관리자

### ★ Oracle 계층형 질의

```sql
SELECT 칼럼
FROM 테이블
START WITH 조건         -- 루트 행 지정
CONNECT BY PRIOR 조건; -- 부모-자식 관계 정의
```

### ★ SQL Server 계층형 질의 (CTE 재귀)

```sql
WITH CTE AS (
  SELECT ...           -- 앵커 멤버 (시작점)
  UNION ALL
  SELECT ...           -- 재귀 멤버
  FROM CTE JOIN ...
)
SELECT * FROM CTE;
```

## 셀프 조인 (SELF JOIN)

"동일 테이블 사이의 조인"  
반드시 **테이블 별칭(Alias)** 사용해야 함

```sql
SELECT A.ENAME 사원, B.ENAME 관리자
FROM EMP A, EMP B
WHERE A.MGR = B.EMPNO;
```
